Numbers on the tags

All from the mystery pack’s settings: a right charge +5 to you (correctGuessReward) and −5 to them (exposePenalty), a wrong one −5 (wrongGuessCost), 3 charges (guessLimit, for the whole game, which is one night), and 10 minutes before you can charge the same suspect again (guessCooldownMin, the engine default; the pack doesn’t set it). The tags should read them from settings, so a GM’s change keeps the tour right.

Words to settle

Form 3’s terms and its upheld screen say “the Board”; the rest of the pack says log book, and so do the tags. Only missions still in a suspect’s hand can be exposed: one already submitted or done is safe, so a right guess about it is dismissed. Worth a line on stop 9 if players trip on it.

Build

A specimen game state for the tabs before 19:00 (Priya, a charge, a blown cover), a spotlight layer over the app frame, an anchor on each real element a stop points at, and the tag as one component: the body is HTML (clip-path and a masked hole) and the eyelet and twine one SVG symbol, so every tag hangs the same way at any size.
